# Готовые лабораторные I–III

Исходный вариант 20: в I и II используется вариант 9, в III — вариант 8.

1. Распакуйте архив целиком в обычную папку.
2. Откройте `lab01`, `lab02` или `lab03`.
3. Запустите `run.bat` двойным щелчком. После вычислений окно останется открытым до нажатия клавиши.

Нужна Windows 10/11 x64. Устанавливать Visual Studio, CMake или Visual C++ Redistributable не требуется. Можно перенести только папку одной лабораторной вместе с её содержимым.

`run.bat` лишь запускает `.exe` из `bin/Release` и сохраняет окно с результатами. Компиляции и загрузок из интернета при этом нет. Сам `.exe` также запускается напрямую. Из терминала доступны параметры, например:

```powershell
.\lab01\bin\Release\lab01.exe --size 16
.\lab02\bin\Release\lab02.exe --repeats 3
.\lab03\bin\Release\lab03.exe --size 100000
```

Без параметров используются полные размеры: 2000 для I–II, 50 000 000 для III. При нескольких повторах показывается медиана. Полные вычисления могут занять заметное время; программа сообщает, какой метод выполняется. Для III желательно иметь не менее 2 ГБ свободной оперативной памяти. При нехватке памяти закройте другие программы либо уменьшите `--size`; уменьшенный запуск служит проверкой и не заменяет замер на полном размере.

Описание задания и реальные измерения находятся в README каждой лабораторной. В архиве готовые программы; для изменения кода и повторной компиляции нужен исходный проект и инструменты C++.
