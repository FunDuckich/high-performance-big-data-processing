# Лабораторная II — преобразование контейнеров

Исходный вариант 20; `(20 - 1) % 11 + 1 = 9`. Вход: `x_n = 100 cos(n)`, `n = 1,...,2000`.

```text
M = max(20, floor(20 |x|))
y_n = f(x_n)
f(x) = sum(k=1..M) sum(j=1..M)
       x² (k² + j²) / (x² + k⁴ + j⁴) · cos((k-j)x)
```

Сравниваются `std::transform` и `concurrency::parallel_transform` для `std::vector`, `std::deque`, `std::list`. Исходные контейнеры не изменяются, выходные контейнеры выделены заранее и имеют тот же тип и размер.

## Запуск

Двойной щелчок по `run.bat` запускает полное задание и сохраняет окно с результатами. Из терминала в этой папке:

```powershell
.\bin\Release\lab02.exe
.\bin\Release\lab02.exe --size 16
.\bin\Release\lab02.exe --repeats 3
```

`--size` изменяет число элементов, полный размер — 2000. `--help` показывает параметры. Сборка из корня исходного проекта: `build.bat lab02`. Для готовой программы нужна Windows 10/11 x64; установка компилятора не требуется. `.exe` можно запускать напрямую; `run.bat` нужен только для удобного сохранения окна после завершения.

## Проверка и измерения

Подготовка входов, выделение и очистка выходных контейнеров, проверка результатов не входят в замер. Локальные таблицы косинусов и степеней вычисляются внутри `f` и входят во время обоих методов; порядок суммирования сохранён. Сравниваются все элементы, отклоняются неконечные значения, выводится максимальная абсолютная ошибка. При повторениях чередуется порядок методов и показывается медиана. Отдельного прогрева нет.

Полный запуск 6 октября 2026 года: AMD Ryzen 5 3600, 6 ядер / 12 логических процессоров, 16 ГБ ОЗУ, Windows x64 (сборка 26200), MSVC 19.44, Release `/MT`. Размер 2000, три повтора; в таблице медианы времени.

| Контейнер | std::transform, с | parallel_transform, с | Ускорение |
|---|---:|---:|---:|
| vector | 5.035926 | 0.871013 | 5.782 |
| deque | 5.044684 | 0.869791 | 5.800 |
| list | 5.037008 | 0.881503 | 5.714 |

Все результаты совпали поэлементно; максимальная абсолютная ошибка равна нулю. Параллельное преобразование ускорило обработку всех трёх контейнеров примерно в 5,7–5,8 раза. Каждый выходной элемент зависит только от своего входного, поэтому разные элементы вычисляются одновременно и записываются в разные позиции выходного контейнера. Наименьшая медиана получилась у дека, но разница с вектором меньше 1%; уверенного общего преимущества одного контейнера эти измерения не показывают.
